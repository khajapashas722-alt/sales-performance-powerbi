## 2. Core DAX Concepts Explained

### Time Intelligence with `SAMEPERIODLASTYEAR()`
```dax
Revenue Prior Year (PY) = 
CALCULATE(
    [Total Revenue], 
    SAMEPERIODLASTYEAR(Dim_Date[Date])
)
```
- `SAMEPERIODLASTYEAR` shifts the current date filter context back by exactly one year.
- Wrapping `[Total Revenue]` inside `CALCULATE()` evaluates the total sales across that prior period, enabling dynamic Year-over-Year (YoY) variance tracking across any slicer selection (Year, Quarter, Month).

### Protecting Against Division Errors with `DIVIDE()`
```dax
Profit Margin % = DIVIDE([Total Profit], [Total Revenue], 0)
```
- In financial analytics, lines with zero sales will crash standard division (`/`) with a `#DIV/0!` error. `DIVIDE` evaluates the denominator safely and defaults to 0.

## 3. Three Improvements You Can Personally Implement

1. **What-If Parameter for Price Elasticity**:
   - In Power BI Desktop, click **Modeling** -> **New Parameter** -> **Numeric Range**.
   - Create a parameter for `Price Adjustment % (-20% to +20%)` to simulate how price increases impact net margin.
2. **Dynamic Tooltip Report Page**:
   - Create a small canvas page (Tooltip size) showing a mini line chart of 12-month sales. Configure it as a hover tooltip on the Category matrix visual.

   - Add a Decomposition Tree visual breaking down `[Total Profit]` by Category -> Sub-Category -> Region -> Customer Segment to visually trace where margin degradation occurs.
